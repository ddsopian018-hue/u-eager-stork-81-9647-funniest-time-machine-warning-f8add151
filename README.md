A deadpan safety notice for a time machine: it warns the operator never to use the machine to prevent their own birth, then calmly informs unborn passengers that they will still be billed for the trip anyway. The grandfather paradox, delivered with the straight face of a genuine warning label and the punchline saved for the last few words.
